## 2. Keyboard-Only Walkthrough Log (Tab Order & Focus Management)

A user navigating exclusively with the keyboard (`Tab`, `Shift+Tab`, `Space`, `Enter`, `1-4`, `Escape`) can complete the entire diagnostic exam lifecycle:

1. **Authentication Route (`/auth/login`)**:
   - `Tab 1`: Focus shifts to Email input field (`#auth-email`).
   - `Tab 2`: Focus shifts to Password input field (`#auth-password`).
   - `Tab 3`: Focus shifts to "Authenticate Session" submit button (`type="submit"`). Focus ring `ring-2 ring-cyan-400 ring-offset-2 ring-offset-slate-950` clearly visible.
   - `Enter`: Form submits asynchronously.

2. **Dashboard Navigation (`/dashboard`)**:
   - `Tab 1`: Focus reaches "Start New Diagnostic Session" CTA button.
   - `Enter` or `Space`: Initiates new session and routes to `/quiz`.

3. **Active Quiz Route (`/quiz`)**:
   - `Key 1-4`: Global keyboard listener intercepts numeric key presses (`1`, `2`, `3`, `4`) to instantly select the corresponding option radio button without mouse interaction.
   - `Tab`: Navigates to the radio group and between individual options with arrow keys (`Down`/`Up`).
   - `Tab`: Reaches "Submit Answer" button. `Enter` triggers attempt submission.
   - `Screen Reader Live Announcement`: `role="status"` with `aria-live="polite"` announces: *"Correct! Diagnostic Criteria Verified — Rapid elasticity automatically scales compute capacity."*
   - `Tab`: Focus shifts to "Next Question" or "Finalize & Score Session" button. `Enter` executes action.

4. **Results Screen (`/quiz/results`)**:
   - `Meter Role`: Aggregate score announced via `role="meter"` with `aria-valuetext="80% — Exam Ready (70%+ & All Domains ≥60%)"`.
   - `Progressbar Roles`: Domain breakdowns announce individual proficiency percentages via `role="progressbar"`.
   - `Tab`: Focus reaches "View Candidate Dashboard" button. `Enter` returns to dashboard.

5. **Modals & Overlays (`Modal.tsx`)**:
   - Upon opening, focus is locked to dialog container via `modalRef.current?.focus()`.
   - Pressing `Escape` invokes `onClose` handler and dismisses the dialog immediately.
